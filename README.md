# Shepherd Bible

**Bible study and reading across platforms.**

Shepherd Bible is a multi-platform Bible application ecosystem focused on helping people read, study, understand, and share God's Word.

This repository contains the public website and supporting resources for the Shepherd Bible ecosystem.

🌐 **Website:** https://shepherdbible.github.io/

---

## About Shepherd Bible

Shepherd Bible is being developed as a multi-platform Bible experience.

The goal is to provide a consistent and useful Bible application across different devices and platforms while continuing to expand Bible study, reading, sharing, and community features.

### Platforms

- 🪟 **Windows**
- 🤖 **Android**
- 📱 **Mobile**
- 🌐 **Web**
- 🍎 **Future platforms**

The platform implementations may use different technologies, while the Shepherd Bible experience and ecosystem continue to grow across devices.

---

## Applications

### Shepherd Bible for Windows

The Windows application provides a full Bible reading and study experience for desktop users.

Key areas include:

- Multiple Bible versions
- Bible reading
- Bible search
- Bible study
- Notes
- Highlights
- Bookmarks
- Ebooks
- Verse sharing
- Verse image creation
- Personal Bible data
- Backup and restore
- Community features

The Windows application is distributed through the Microsoft Store.

---

### Shepherd Bible for Android

The Android application brings the Shepherd Bible experience to mobile devices.

The mobile experience is designed for:

- Bible reading
- Scripture study
- Searching the Bible
- Personal notes
- Highlights
- Bookmarks
- Verse sharing
- Mobile Bible study

---

### Future Platforms

Shepherd Bible is intended to continue expanding to additional platforms as development progresses.

Possible platforms include:

- iOS
- macOS
- Web
- Additional desktop platforms

# Shepherd Bible Website

The website acts as the public home of the Shepherd Bible ecosystem.

It is used to:

- Introduce Shepherd Bible applications
- Provide application information
- Highlight features
- Publish changelogs
- Provide FAQs
- Provide privacy information
- Introduce community features
- Provide Bible resources
- Showcase new applications and tools
- Link users to the appropriate platform
